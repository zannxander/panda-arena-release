# Puzzle And Detective Arena

This repository is only for public release notes and download links for PANDA.

PANDA is an unofficial fan-made simulator for testing and playing Puzzle And Detective Arena. It is not affiliated with, endorsed by, or sponsored by the original rights holders.

## Downloads

Download the latest version from:

https://github.com/zannxander/panda-arena-release/releases/latest

Latest version: `0.3.1`

Current release targets:

- Windows
- Android

macOS builds are not included in this release repository.

## Visual Resources

Official card images, official logos, trademark artwork, and other official visual materials are not used, included, bundled, or distributed in this repository or in release assets.

The game supports user-provided local images. Put compatible image files into the `card_images` folder next to the game executable, or import image packs inside the client on supported platforms.

## Notes

- This repository does not contain the Godot project source.
- Release files should be attached to GitHub Releases instead of committed to Git.
- Please use the in-game bug report function when reporting issues.
